# Nutrie-plan-frontend-exam
A JavaScript-based meal and nutrition web application developed as part of a comprehensive JavaScript examination. The project demonstrates practical understanding of modern JavaScript concepts, including ES6+, API integration, DOM manipulation, CRUD operations, asynchronous programming, and dynamic UI updates.

The application integrates external APIs to allow users to explore meals by category and country, search for products by name or barcode, and build a personalized weekly meal tracker. Users can save the meals they consume, track calories and nutritional information, and manage their weekly food records through CRUD functionality.

The project focuses on applying JavaScript concepts in a real-world application rather than simply demonstrating them individually.
